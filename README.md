Real Estate Price Predictor
 Overview

A machine learning web app that predicts property prices based on features like area, location, builder, and property type.

Live App
 (https://realestate-eda-xpm9nejc9anm7ouvvjzgyk.streamlit.app/)

Problem

Real estate pricing is often:

Inconsistent
Non-transparent
Hard to evaluate across locations

 This makes it difficult for buyers and investors to make informed decisions.

 Solution

Built an Automated Valuation Model (AVM) that:

Predicts property prices
Calculates price per sqft
Classifies properties (Budget / Mid / Premium)
Provides a simple web interface for instant insights


 What was done
 Data cleaning & EDA
 Feature engineering & preprocessing
 Model building (Random Forest)
 Model evaluation (MAE, R²)
 Streamlit web app development
 Deployment with external model loading

 
 Tech Stack
Python
Pandas, NumPy
Scikit-learn
Streamlit

 Features
Real-time price prediction
Price per sqft calculation
Clean, interactive UI
Lightweight & deployable model
